# sql-exploratory-data-analysis-project
This SQL project consists of quries that will help you explore and understand the database before performing any operations on it.
We perform Data Exploration, Dimension Exploration, Date Exploration, Measures Exploration, Magnitude Analysis and Ranking Analysis to understand the measures and dimensions which will be used in creating business transformation.
